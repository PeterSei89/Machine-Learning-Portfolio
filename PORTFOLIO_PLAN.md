# Machine Learning Portfolio Plan

## Project 1: Demand Forecasting

Predict future product demand using historical sales data.

## Project 2: Predictive Maintenance

Predict equipment failure using sensor and maintenance data.

**Skills:** classification, feature engineering and model evaluation

## Project 3: Risk or Fraud Detection

Identify unusually risky transactions or records.

**Skills:** imbalanced classification, anomaly detection and explainability
